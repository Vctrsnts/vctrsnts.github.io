Comandos básicos para administrar Continuwuity

2026-11-08 · 4 min · @Self-Hosting · #matrix #Continuwuity

Este artículo viene a continuación de este otro, en el que explicaba brevemente algunos de los comandos que he necesitado para gestionar mi servidor de Matrix con Continuwuity. Puede que, si utilizas este mismo servidor, te resulten tan útiles como me han resultado a mí.

◇ Consultar la ayuda

Lo más básico, y lo que siempre se recomienda pero que nunca hacemos (me incluyo a mí mismo 😅), es consultar la ayuda de los comandos que vamos a utilizar.

Por ejemplo, si queremos consultar las opciones disponibles para eliminar un alias, podemos hacerlo así:

!admin rooms alias remove --help

Esta forma de consultar la ayuda se aplica también a los diferentes comandos disponibles.

◇ Gestión de alias de las salas

Los alias permiten acceder a una sala mediante un nombre fácil de recordar, por ejemplo, #novedades:matrix.servidor.org, en lugar de tener que utilizar su identificador interno.

Nota

Esto es precisamente lo que me sucedía cuando quería utilizar Apprise en unRAID: no aceptaba el identificador de la sala, pero sí su alias. Puedes encontrar más información aquí.

◈ Consultar los alias

Si queremos obtener un listado de los alias locales que tenemos registrados en el servidor, tendremos que utilizar el siguiente comando:

!admin rooms alias list

◈ Comprobar a qué sala apunta un alias

Si queremos comprobar a qué sala pertenece un alias, podemos utilizar el siguiente comando:

!admin rooms alias which #novedades:matrix.servidor.org

◈ Eliminar un alias

Si queremos eliminar un alias local, Continuwuity solo necesita la parte local del nombre, es decir, sin la almohadilla ni el dominio.

Esto es algo que descubrí después de intentar eliminar el alias completo:

!admin rooms alias remove #novedades:matrix.servidor.org

El servidor respondió con un error al intentar interpretar el dominio. El motivo es que el comando remove no admite el alias completo, sino únicamente su parte local.

Por tanto, para eliminar #novedades:matrix.servidor.org, tendremos que utilizar:

!admin rooms alias remove novedades

Nota

Eliminar un alias no elimina la sala. Únicamente libera ese nombre para que podamos volver a utilizarlo.

◈ Consultar cómo asignar un alias

Para conocer la sintaxis necesaria para asignar un alias a una sala, podemos consultar la ayuda del comando de la siguiente manera:

!admin rooms alias set --help

Este comando muestra las opciones que admite la versión instalada de Continuwuity. Conviene consultarlas antes de asignar un alias nuevo.

◇ Tokens de acceso para automatizaciones

Cuando utilizamos scripts para enviar notificaciones a Matrix, necesitamos un token de acceso que permita autenticarlos sin tener que iniciar sesión manualmente cada vez.

◈ Emitir un token desde Continuwuity

A través de Continuwuity podemos obtener un token de acceso para un usuario mediante el siguiente comando:

!admin users issue-token <USERNAME> <PASSWORD>

Los argumentos necesarios son:

  • USERNAME: nombre de usuario de Matrix.
  • PASSWORD: contraseña de esa cuenta.

Si queremos consultar la sintaxis del comando, podemos utilizar:

!admin users issue-token --help

Si ejecutamos el comando sin proporcionar los argumentos necesarios, Continuwuity muestra un error indicando que faltan el nombre de usuario y la contraseña.

◈ Caducidad de los tokens

Este es un aspecto que todavía no tengo del todo estudiado. No sé si los tokens emitidos mediante este comando tienen una caducidad configurable ni si existe algún procedimiento oficialmente soportado para mantenerlos válidos a largo plazo.

Para las automatizaciones, conviene utilizar una cuenta dedicada y tener claro cómo renovar o revocar el token en caso necesario.

Tampoco hay que confundir los tokens de acceso de Matrix con los tokens de registro ni con los tokens temporales de inicio de sesión, ya que tienen finalidades diferentes.

Tengo que decir que el token que creé para el envío de mensajes sigue activo. Esto me hace pensar que no tienen una caducidad inmediata, aunque no puedo asegurar que sigan siendo válidos indefinidamente.
