Descomprimir ZIP automáticamente con Bash

2026-10-21 · 3 min · @Programación · #Bash #Arch

A continuación tienes un script muy corto que permite descomprimir todos los archivos .zip de un directorio, creando una carpeta para cada uno y colocando allí su contenido.

#!/usr/bin/env bash
# bucle.sh – Descomprime todos los .zip del directorio actual

for f in *.zip; do
    # Crea la carpeta con el mismo nombre que el archivo (sin la extensión .zip)
    mkdir -p "${f%.zip}"
    # Descomprime de forma silenciosa dentro de la carpeta creada
    unzip -q "$f" -d "${f%.zip}"
done

Este script lo uso, porque de vez en cuando descargo multiples archivos en zip. Pero no 1 o 2, sino 10 o más.

Si tienes 1 o 2, pues no es molestia descomprimirlos, pero cuando tienes unos cuantos, pues es una molestia tener que ir archivo por archivo descomprimirlos, y para ello, me he creado el siguiente script.

◇ Como funciona

  • Bucle for: recorre cada archivo que termina en .zip en el directorio actual.
  • mkdir -p "${f%.zip}": crea la carpeta destino con el nombre del archivo, eliminando la extensión .zip. La opción -p evita errores si la carpeta ya existiera.
  • unzip -q "$f" -d "${f%.zip}": extrae el contenido del zip de forma silenciosa (-q) dentro de la carpeta recién creada.

◈ Consideraciones

  • Archivos originales: No se borran; el script solo crea copias descomprimidas.
  • Si una carpeta de destino ya existe: Si ya existe, se reutiliza; los archivos extraídos pueden sobrescribir los que haya dentro.
  • Ambito: Sólo procesa los ZIP del directorio donde se ejecuta, no busca recursivamente en subdirectorios.
  • Si no hay archivos .zip: Si no hay coincidencias, Bash podría tratar *.zip como texto literal. Activa nullglob (shopt -s nullglob) si prefieres que el bucle se omita en ese caso.

◇ Ejemplo de uso

  1. Guarda el script en un archivo llamado bucle.sh y dale permisos de ejecución:

    chmod +x bucle.sh

  2. Ejecuta el script en la carpeta que contiene los archivos ZIP:

    ./bucle.sh

◈ Estructura antes y después

mi_carpeta/
├── fotos.zip
├── documentos.zip
└── copias.zip

Después de ejecutar bucle.sh:

mi_carpeta/
├── fotos.zip
├── fotos/
│   └── … (contenido descomprimido)
├── documentos.zip
├── documentos/
│   └── … (contenido descomprimido)
├── copias.zip
└── copias/
    └── … (contenido descomprimido)

Cada carpeta (fotos, documentos, copias) contiene los archivos extraídos del zip correspondiente.

◇ Conclusión

Este pequeño script automatiza la extracción de múltiples archivos ZIP y organiza su contenido en directorios independientes.
